# مشروع ميزان — الزاحف القانوني السوري

هذا المستودع هو نواة **طبقة جمع واستخراج البيانات القانونية** لمشروع ميزان. يحتوي حالياً على نموذج أولي لزاحف مهذب، ومستخرج نصوص قانونية، وطبقة SQLite تجريبية.

> المشروع الحالي لا يحتوي بعد على FastAPI أو PostgreSQL/pgvector أو Embeddings أو RAG أو تطبيق Flutter. الخطة الكاملة للانتقال من النموذج الأولي إلى منصة ميزان موثقة في [docs/ROADMAP.md](docs/ROADMAP.md).

## الحالة الحالية

- `recon.py`: استطلاع بنية المصدر.
- `fetcher.py`: جالب HTTP مع تأخير وإعادة محاولة.
- `extractor.py` v3.3: تنظيف أولي واستخراج مواد قانونية.
- `crawler.py` v2.1: زحف أولي وحفظ في SQLite.
- `database.py`: مخطط SQLite تجريبي.
- لا توجد حالياً نسخة قاعدة بيانات أو بيانات إنتاجية ضمن Git.
- عدد المواد المستخرج فعلياً من بيئة خارجية غير قابل للتحقق من هذا المستودع وحده.

## مبدأ العمل

لن يتم الانتقال إلى الزحف واسع النطاق أو بناء RAG قبل تثبيت جودة الاستخراج، قابلية الاستئناف، سلامة مصدر البيانات، ومنع التكرار. كما أن أي قرار متعلق بدمج هذا المستودع مع `lawyer-office2` يجب أن يسبقه فحص فعلي لذلك المستودع، لا افتراضات.
