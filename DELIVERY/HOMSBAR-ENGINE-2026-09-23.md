# محرّك فرع نقابة حمص — `homsbar_source.py` (ف٥، 2026-09-23)

## ما بُني
محرك حصاد كامل لموقع `homsbar.org` تطبيقاً لمبدأ «كل رابط هو موقع»
(مواصفة الفحص: `DELIVERY/SOURCE-REFINEMENT-2026-09-23.md`).

**المسار:** خريطة ووردبريس الأساسية `wp-sitemap.xml` ⇒ خرائط `juris_article`
(12 مقالاً) ⇒ جلب كل صفحة ⇒ استخراج روابط الرفع
(`wp-content/uploads/...` بامتدادات doc/docx/zip/pdf/txt) ⇒ تنزيل مهذب
بإعادة محاولة ⇒ تفريغ النص محلياً بحسب البصمة الفعلية للملف ⇒ المحلل العام
`parse_text` ⇒ بوابة `min_hits=3` استشهادات بهوية ⇒ كتابة عبر `ingest_page`
نفسها ⇒ حالة `pending` حتى الاعتماد.

## تفريغ الملفات — بلا أي تبعية جديدة
| البصمة | المعالجة |
|---|---|
| `PK..` وفيه `word/document.xml` | docx: قراءة `document.xml` مع حدود الفقرات `</w:p>` |
| `PK..` بلا `document.xml` | أرشيف مضغوط: تكرار داخلي حتى عمق 2 (حماية: 200 عضو / 50مب كحد أقصى) |
| `%PDF` | pymupdf (التبعية الموجودة أصلاً؛ غيابه لا يكسر غيره) |
| `\xd0\xcf\x11\xe0` (Word 97-2003 الثنائي) | استخراج استرشادي بترميزي العربية الشائعين (UTF-16LE وCP1256) مع فلترة المقاطع العربية — والمحضر الأخير لبوابة الجودة لا للاستخراج |
| `<html…` | مسار `article_text` المعتاد |

ملاحظة قياس: مرفق العينة الحي («اجتهادات هيئة عامة فقط 2003 وماقبل»، جمع
القاضي عبدالقادر عنتر) امتداده `.doc`؛ فإن كان ملف وورد ثنائياً حقيقياً سلك
المسار الاسترشادي، وإن كان وورد حديثاً مقنّعاً بالامتداد (شائع في رفعات
2015) سلك مسار الأرشيف/النص مباشرة — البصمة لا الامتداد هي الحكم.

## الاستئناف والتهذيب
- هوية المقال = رابط صفحته؛ `already_ingested` يمنع إعادة التنزيل بين الجلسات.
- تأخير مهذب 1.0ث بين الصفحات و0.5ث بين المرفقات، مع إعادة محاولة متصاعدة.
- `--dry` يقيس بلا كتابة؛ `--pages N` سقف للاختبار.

## القيادة
```
python -m cli precedents-homsbar --dry     # قياس أولي بلا كتابة
python -m cli precedents-homsbar           # الحصاد الكامل → pending
```

## الاختبارات (`tests/test_homsbar_source.py` — 5 اختبارات، كلها ناجحة)
1. حصاد طرف-إلى-طرف بخريطة موقع وصفحة ومرفق docx مُصنَّع: 3 استشهادات
   تُكتب، والمقال لا يُعاد في الجولة الثانية (`seen`).

3. استخراج الروابط: دمج المكرر النسبي/المطلق بعد تطبيع `www.` ورفض الصور.
4. التفريغ: docx، أرشيف يحوي docx، وملف وورد ثنائي قديم بنص عربي بين ضجيج.
5. تعداد الخرائط يلتقط `juris_article` وحدها.
