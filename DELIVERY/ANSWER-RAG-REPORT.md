# تقرير التسليم 6 — الجواب الموثَّق محلياً (إعادة تأطير ADR-001)

**التاريخ:** 2026-09-05 — **الحالة:** مُسلَّم بتحقق حي (76 اختباراً + eval 6/6)

## 1. السياسة (بلا ادعاء توليدي)

- **الجواب = نص المادة حرفياً** من المتن (كامل المادة عبر `article_id`،
  لا القطعة التي قد تكون جزءاً). لا وسيط لغوي يخطئ أو يهلوس.
- **الاستشهادات:** وثيقة + لفظية + رقم مادة + رابط المصدر، لكل ضرب.
- **الرفض الآمن:** لا ضرب ⇒ «لا مصدر كافٍ — لا يُستنتج جواب» تُعرض
  صراحة في CLI والواجهة؛ ليست خطأً تقنياً بل نتيجة مقصودة (§8.3 ميزان).
- الشفافية: لا تُذكر درجات مخفية؛ الرفض/القبول ثنائيان ومفهومَان للمحامي.

## 2. المنفذ

| المكوّن | الوصف |
|---|---|
| `answer.py` | `answer_question` (جواب+استشهادات/رفض) و`run_qa_eval` |
| `cli ask "سؤال"` | يطبع الجواب الحرفي والاستشهادات أو ⛔ الرفض |
| `cli eval-qa` | دقة إسناد الجواب + دقة الرفض الآمن → `output/qa_eval.md` |
| شاشة «جواب موثَّق» | الصفحة الخامسة؛ سؤال ⇒ جواب من المتن + قائمة استشهادات |

## 3. الأرقام الحية (القاعدة الحقيقية، 2026-09-05)

```
على متن 54 وثيقة / 3784 قطعة (متن الطيار الآلي):
دقة الإسناد = 1.00 | دقة الرفض الآمن = 1.00 | مُجاب: 11 / مرفوض: 1 (12/12 ✓)
```

مثال حي: «ما عقوبة من خطف شخصاً بقصد تحقيق مأرب سياسي أو مادي؟» ⇒ نص
المادة كاملاً + استشهادات عبر مصدرين (المنتدى ومحامة). وسؤال «رهن
السفينة» ⇒ ⛔ «مصدر ضعيف — لا جواب» (قاعدة ≥2 رمز محتوائي،
`search.is_weak` — «السوري» نفسها ليست رمزاً محتوائياً لأن المتن كله
سوري: درس الطيار الآلي).

## 4. علّة وُجدت وأُصلحت

`search` لم يكن يعيد `article_id` في المسارين (FTS والاحتياطي) فكان
الجواب يسقط بـ KeyError قبل الوصول لنص المادة الكامل — أُضيف العمود
للاستعلامين واختُبر (الجواب يبدأ بنص المادة الكامل).

## 5. المؤجل صراحةً (مسار خادمي اختياري — ADR-001)

API الوثائق/البحث/إدارة الزحف، OpenAPI، مصادقة وتفويض، وتقييم QA على
متن أوسع. والـRAG التوليدي الحقيقي (Qwen محلي) يبقى — كما قررت خطة
ميزان — داخل تطبيق Flutter عبر llamadart، تغذيه حزم هذا المستودع.
