# تطبيق تحديث تقييم المصادر على Windows

النسخة التي شغّلتها في `C:\Users\ASUS\Desktop\SyrianLawCrawler` لم تكن قد استلمت تعديلات التقييم الآلي، لذلك ظل `autopilot` فيها يبدأ الزحف افتراضياً.

## الحزمة

`SOURCE-ASSESSMENT-UPDATE-2026-09-26.zip` تحتوي ملفات الكود المعدّلة فقط. لا تحتوي قاعدة البيانات `data\syrian_law.db`، ولا `.env`، ولا أي أسرار.

## الخطوات

1. أوقف البرنامج وأغلق التطبيق إن كان مفتوحاً. احتفظ بنسخة احتياطية من مجلد المشروع أو على الأقل قاعدة البيانات.
2. فك ضغط الحزمة **داخل جذر المشروع نفسه**:
   `C:\Users\ASUS\Desktop\SyrianLawCrawler`
   وافق على استبدال ملفات الكود المطابقة فقط. لا تحذف `data` ولا `.env`.
3. افتح CMD أو PowerShell في ذلك المجلد، وتأكد أن `dir cli.py` يعرض الملف.
4. شغّل الهجرة؛ ستُنشأ نسخة احتياطية تلقائياً قبل إضافة حقول التقييم:

   ```bat
   python -m cli migrate
   ```

5. شغّل الاكتشاف الآمن:

   ```bat
   python -m cli autopilot --max-evaluate 12
   python -m cli sources list
   ```

بعد التحديث، `autopilot` يقيّم ويسجّل المقترحات فقط افتراضياً، ولا يعتمدها أو يبدأ الزحف. إذا حُجب DDG أو انتهت مهلته، يتوقف استخدامه لباقي الدورة بدل إرسال طلب جديد لكل استعلام؛ الحد الأعلى 12 استعلاماً، ومهلته أقصر. ولإعادة تقييم مصدر قديم بعينه بعد التحديث، استخدم رابط المصدر نفسه:

```bat
python -m cli sources add "https://example.org/legal-page"
```

الأمر لا يغيّر قرار الاعتماد السابق. إذا عاد DuckDuckGo بـHTTP 202 أو 403، فهذه قناة البحث محجوبة؛ لن تظهر مرشحات بحث جديدة من DDG في تلك الدورة. يمكن استخدام Bing فقط عند ضبط `BING_API_KEY` في بيئة التشغيل.
