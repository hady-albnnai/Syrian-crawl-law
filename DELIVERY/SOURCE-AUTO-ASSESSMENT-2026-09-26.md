# التقييم الآلي للمصادر — 2026-09-26

## القرار التشغيلي

نُفّذ خيار المستخدم: **الزاحف يكتشف المصدر ويقيّمه ويسجّل النتيجة للمراجعة فقط**.
لا اعتماد تلقائياً، ولا رفض لحالة المصدر بسبب الدرجة، ولا بدء زحف من دورة الاكتشاف.
الاعتماد والزحف مرحلتان منفصلتان وتبقيان بقرار المستخدم.

## ماذا يقيس التقييم؟

كل مرشح يُجلب عبر `fetcher.fetch` المهذّب (robots والتأخير وإعادة المحاولة)، ثم
يُفحص آلياً من الصفحة المكتشفة:

- فئة رسمية النطاق من القائمة الصريحة في `config.OFFICIAL_DOMAIN_TIERS`؛ لا تُمنح
  الرسمية تلقائياً لكل نطاق ينتهي بـ`gov.sy`.
- نوع المحتوى: تشريعات، اجتهادات، مختلط، قانوني محتمل، أو غير قانوني.
- بنية التشريع: المواد المستخرجة وروابط القوانين الداخلية.
- بنية الاجتهادات: استشهادات لها هوية قرار يستخرجها `precedent_parser`، وروابط
  الاجتهادات الداخلية. ورود كلمة «قرار» وحدها لا يكفي كدليل قوي.
- اكتمال النص عند وجود مواد، طول النص، محرك الموقع، وإمكانية الوصول.

الدرجة من **0 إلى 100** قابلة للتفسير: الرسمية (حدها 25)، الصلة القانونية (35)،
البنية والأدلة (25)، اكتمال النص (8)، والوصول (15)، مع سقف نهائي 100.
يسجَّل أيضاً الحكم الآلي والأسباب ومكوّنات الدرجة والأدلة بصيغة JSON داخل سجل
`source`؛ هذه **توصية تقييمية وليست قرار اعتماد**.

## حالة المصدر مستقلة عن نتيجة التقييم

- نتيجة التقييم مثل `recommended` أو `needs_review` أو `rejected` تُحفظ في
  `evaluation_verdict`.
- حالة المصدر في وضع المقترحات تبقى `proposed` حتى لو صنّفه التقييم منخفض الصلة.
- يعرض `python -m cli sources list` درجة المصدر ونوعه وأسباب التقييم.
- إعادة التقييم تحدّث الأدلة والدرجة الأخيرة، ولا تمحو قراراً بشرياً سابقاً.

## التشغيل

```bash
# يبحث ويقيّم ويسجل للمراجعة؛ لا اعتماد ولا زحف تلقائي
python -m cli autopilot --max-evaluate 12

# راجع الدرجات والأسباب
python -m cli sources list

# بعد المراجعة والاعتماد اليدوي فقط، إن رغبت
python -m cli sources approve <ID>
python -m cli crawl --pages 20 --mode limited
```

واجهة سطح المكتب تتبع السياسة نفسها: زر الاكتشاف يقيّم ويسجل فقط، وخيار الاعتماد
الآلي معطّل. في CLI/API أصبحت القيم الافتراضية أيضاً `auto_approve=False` و
`crawl=False`؛ فلا يبدأ الزحف إلا بخيار صريح منفصل.

## قاعدة البيانات والتوافق

أضيفت الهجرة **013** وحقول تقييم داخلية في جدول `sources` لحفظ الدرجة، النوع، الحكم،
الأسباب، الأدلة، وقت التقييم، وعدد الصفحات المفحوصة. لم يتغير عقد CSV أو ملفات
Mizan أو مسار تصديرها؛ لا يمس التقييم صفوف Mizan.

## التحقق والحدود

- الاختبارات المحلية ذات الصلة: **102 ناجحاً** عبر التقييم، الطيار، جودة المصدر،
  الهجرات، التعلم، وتوصيلات بيانات الواجهة. فحص `py_compile` نجح للملفات المعدّلة.
- اختبار الواجهة `tests/test_ui_v5.py` لم يبدأ لأن `PySide6` غير مثبت في البيئة.
- بعد ملاحظة الحجب، حُدِّثت قناة البحث لتتوقف عن مزوّد فاشل لباقي الدورة، مع مهلة اتصال/قراءة أقصر، وسقف 12 استعلاماً موزعاً بين الفجوات والتشريعات والاجتهادات. هذا تعديل كود واختُبر محلياً؛ لم يُشغّل اكتشاف حي أو زحف خلاله.
- الدرجة الحالية تقيم **الصفحة التي اكتشفها البحث** (مع قراءة روابطها الداخلية)،
  ولا تعني فحص الموقع كاملاً أو ضمان صحة كل محتواه. كما أن رسمية النطاق تعتمد على
  القائمة الموثقة؛ المصادر الرسمية الجديدة تحتاج مراجعة وإدراجاً صريحاً.
